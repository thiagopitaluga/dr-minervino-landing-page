# Dr. Minervino — Landing Page

Landing page premium e responsiva para o Dr. Antonio Sérgio Leite Minervino,
urologista em São Luís (MA).

## Objetivo

- posicionar autoridade e percepção de valor;
- comunicar especialidades com clareza e discrição;
- conduzir o visitante ao agendamento pelo WhatsApp;
- oferecer uma experiência fluida em desktop e mobile.

## Desenvolvimento local

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

## Validação

```bash
npm test
```

O projeto utiliza React, vinext, TypeScript e CSS responsivo.
